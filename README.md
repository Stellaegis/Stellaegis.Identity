# Stellaegis.Identity

Accounts, login, multi-factor authentication, password reset and the OpenID Connect issuer of an application
assembled on [Stellaegis.Primitives](https://github.com/Stellaegis/Stellaegis.Primitives), plus what a resource
server needs to admit the actors it issues.

⚠ Being extracted from the Stellaegis framework. Nothing is published yet; the first version will be 5.0.0.
